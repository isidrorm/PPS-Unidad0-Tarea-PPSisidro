# GitHub Pages
## Configuración

Se ha habilitado GitHub Pages para publicar la documentación generada con MKDocs.

Para ello, se accedió a: 

```text
Settings -> Pages
``` 

Y se configuró la fuente de despliegue como: 
```text
Branch: gh-pages
Folder: /root
```

Tras finalizar el workflow de GitHub Actions, la documentación queda publicada en GitHub Pages.

URL de la documentación:

***https://isidrorm.github.io/PPS-Unidad0-Tarea-PPSisidro/***

En el documento PDF se adjunta la información detallada.
