# Actividad Unidad 0 - DevSecOps Básico y Automatización de la Documentación

## Introducción

En esta actividad se han trabajado diferentes tecnologías y herramientas relacionadas con el desarrollo seguro de aplicaciones y la automatización de procesos DevOps.

Durante la práctica se han aplicado conocimientos sobre:

- Lenguaje de marcas Markdown.
- Control de versiones mediante Git y GitHub.
- Automatización CI/CD con GitHub Actions.
- Publicación de documentación mediante GitHub Pages.
- Contenedores Docker.
- Uso de NGINX para publicar documentación web.
- Conceptos básicos de DevSecOps.

El objetivo principal de la actividad ha sido crear un repositorio completamente funcional capaz de generar automáticamente documentación web estática utilizando MkDocs y desplegarla mediante GitHub Pages y Docker.
